# Mi Fitness 体脂秤数据可视化

读取小米官网导出的体脂秤 CSV,用折线图可视化身体成分数据。
**纯静态单文件前端**(Chart.js),CSV 在浏览器本地解析,无后端、无构建、无第三方依赖。

> 在线试用: <https://twt233.github.io/mifit-viewer/> — 打开后点「打开 CSV」选自己的体脂数据即可(数据仅在浏览器本地解析,不上传任何服务器)。

## 功能

- **纯静态**:单 ` index.html ` ,打开即用,可托管在 GitHub Pages
- **本地解析**:CSV 经 FileReader 在浏览器本地解析,数据不离开本机
- **多用户区分**:同一小米账号下体脂秤多个档案( ` account_id ` + ` duid ` )自动识别,下拉切换
- **Grafana 风格时间选择器**:快捷档位(自动/周/双周/月/季/年)+ 自定义日期范围,主界面与大图各有独立实例
- **按天聚合**:同一天多次测量取日均,无测量的天保留坐标位不画点
- **置顶看板**:任意指标可置顶到顶部看板,大卡片展示,选择持久化到 localStorage
- **大图模式**:点击图表卡片全屏查看,可独立调节时间范围
- **纵轴三档**:自动 / 基准(下限圆整到 1·2·5 刻度) / 0
- **23 项身体成分指标**:体重、BMI、体脂率、脂肪量、骨骼肌量、骨盐量、水分、蛋白、基础代谢、内脏脂肪、身体年龄、心率等,按量纲(质量/比率/指数/其他)分组

## 快速开始

直接打开 ` index.html ` ,或访问上面的 GitHub Pages 链接,点「打开 CSV」选择从小米官网导出的 ` *scale_record.csv ` 即可。

## 数据来源

小米官网(账号隐私数据导出)下载的体脂秤数据包,解压后取 ` *scale_record.csv ` (生态链体脂秤数据)。

数据结构参考导出包内的 ` Mi_Fitness-Eco_data_copy_guide.pdf ` 。字段含义已对照手册核对并用数值交叉验证(如 ` bfm≈weight×bfp% ` 、` ffm=weight-bfm ` )。

## 本地预览

直接双击 ` index.html ` 打开,或起个静态服务:

```bash
python3 -m http.server 8000   # 浏览器访问 http://localhost:8000
```

## 隐私

` data/ ` 目录在 ` .gitignore ` 中,个人健康数据不会入库。本仓库只含 ` index.html ` 。

## 技术栈

- 前端: 单 HTML 文件 + Chart.js 4 (CDN)
- CSV 解析、时间选择器、tooltip、卡片网格均为原生 JS 实现
